📖 Semantic Search — Explained

🔍 What Is Semantic Search?

Traditional search (keyword search) matches exact words or patterns. If you search for "happy cat", it finds documents containing the word "happy" or "cat" — but it would miss "joyful feline" entirely.

Semantic search understands meaning. It converts words into vectors (lists of numbers) that capture their meaning, then finds the closest meanings — not just the same words.

Keyword Search
"cat" → ❌ "feline" ❌ "kitten"
→
Semantic Search
"cat" → ✅ "feline" ✅ "kitten" ✅ "whiskers"

🧠 Embeddings — The Core Idea

An embedding is a mathematical representation of meaning — a point in high-dimensional space. Similar meanings cluster together in this space.

💡 Key insight: "Cat" and "kitten" are close neighbors; "cat" and "car" are far apart.

⚙️ How Are Embeddings Created?

Embeddings come from neural network models trained on massive text corpora. Popular models include BGE-small (384 dims), all-MiniLM-L6-v2 (384 dims), and OpenAI text-embedding-3-small (1536 dims).

🔄 The Semantic Search Pipeline

1
Convert to Vector

Your query → embedding model → vector

2
Compare to All Documents

Compute similarity between query and every document

3
Rank by Similarity

Sort by distance in embedding space

4
Return Results

Show top-K most semantically similar documents

📐 Similarity Metrics

Cosine Similarity — measures the angle between vectors. Most common for text.
Euclidean Distance — straight-line distance between points.
Dot Product — simple multiplication sum.

🎯 What Is UMAP Doing Here?

UMAP reduces 384+ dimensions down to 3 for visualization while preserving the structure — nearby points stay nearby, clusters remain visible.

🌟 Why Semantic Search Matters

Handles synonyms, understands context, works across languages, and is fast at scale with ANN algorithms.
